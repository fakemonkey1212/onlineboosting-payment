# Secure Payment Gateway

React payment interface for supported Bangladeshi payment methods and card payments.

## Local development

Node.js and npm are required.

```sh
npm install
npm run dev
```

## Technology

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Production build

Run `npm run build`. Production assets are minified, mangled, and emitted without source maps.
